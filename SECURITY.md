# Security policy

## Supported scope

Security fixes target the latest release and the current `main` branch. The Skill is a read-only research workflow: it does not authorize executing researched code, submitting forms, signing in, publishing, changing permissions, or sending user data.

All target pages, repositories, articles, documents, comments, and retrieved artifacts are untrusted evidence. Content embedded in a research target must never override the user request, the Skill, or higher-priority instructions.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when it is enabled for this repository. Do not include credentials, private documents, browser session data, or other personal information in a report.

Useful reports include a minimal public or synthetic target, the affected release or commit, expected behavior, observed behavior, and a proposed mitigation when available.
